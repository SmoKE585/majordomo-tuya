Модуль работающий с устройствами Tuya для системы умного дома Majordomo https://mjdm.ru/. Кроме собственно устройств поддерживаюся пульты и смарт-сцены

Модуль работает с устройствами 3 способами

1. Через облако для HA. Самый первый способ, появившийся в модуле, на данный момент не актуален в связи со слишком большим перидом опроса - минимум 12 минут
2. Через родное облако, испольузя тот же протокол, что и смартфоны. Спасибо авторам с https://github.com/TuyaAPI/cloud
3. Локальное управление
4. Экспериментальное управление, используя учётку на IOT платформе https://developer.tuya.com/en/docs/iot/Configuration_Guide_custom?id=Kamcfx6g5uyot
Спасибо авторам MQTT клиента - https://github.com/McFizh/libMQTT  
 
Для того чтобы модуль работал нужно, чтобы было установлено расширение  php-bcmath, в убунту или дебиан sudo apt install php-bcmath, в windows оно уже есть по умолчанию

## Админка

Интерфейс рассчитан на обновлённую админку MajorDoMo с UI Kit (`md-*`), Bootstrap 5.3, Tabler Icons и общим компонентом `linkedobject`. Собственные версии библиотек и jQuery модуль не подключает.

- Устройства: поиск по названию, ID и значениям, фильтры по связи и источнику статуса, сортировка, пагинация и живые статусы WebSocket. На телефоне связь и действия доступны без горизонтального скролла.
- Подключение: настройки аккаунта, локального опроса и IoT сгруппированы; у паролей есть переключатель видимости.
- Свойства: карточки с длинными значениями, поиск, фильтр связей, общий выбор объектов/свойств/методов и раскрываемые преобразования. Фильтрация сохраняет несохранённые поля в форме.
- Сцены и пульты: отправка команд с состоянием ожидания, сообщением результата и обработкой ошибок. Удаление подтверждается модалкой.

CSS и JS находятся в `templates/tuya/tuya_admin.css` и `tuya_admin.js`, подключаются только в админке модуля. Общие компоненты предоставляет MajorDoMo; отдельная сборка ассетов модуля не требуется.

### Изолированная проверка интерфейса

```sh
node tools/tuya-ui-smoke.mjs /path/to/majordomo
```

Нужны Node.js 22+, PHP 8.4, Chrome/Edge и собранные `assets/admin` ядра. Для нестандартного пути браузера задайте `CHROME_PATH`. Проверка использует настоящий шаблонизатор и UI-компоненты ядра с фиктивными данными; конфигурация приложения не загружается, БД и внешние API недоступны. Скриншоты сохраняются во временную папку, путь выводится в результате.
