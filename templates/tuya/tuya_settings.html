Аккаунт Tuya

Данные приложения, в котором зарегистрированы устройства.

Например, 7 для России.
Должно совпадать с приложением, где добавлены устройства.

Способы подключения

Включайте только используемые режимы: для выключенных режимов фоновые циклы не запускаются.

Локальный опрос
Оставьте пустым для автоматического определения.
Используется, только если устройство получает статус локально.
Облако
Значения в базе
Первый приём сохраняется сразу, следующие — не чаще интервала. 0 — сохранять каждое значение. Привязанные свойства и методы, а также статус связи обновляются всегда.

Платформа IoT

Ключи проекта с developer.tuya.com. Нужны только для подключения через платформу IoT.
